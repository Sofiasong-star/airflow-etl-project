 ETL-пайплайн курса валют (USD/RUB)

Автоматический ETL-пайплайн на **Apache Airflow**. Он каждые 3 минуты забирает курс доллара из публичного API, обрабатывает его и сохраняет в базу данных **SQLite**. Всё работает в изолированных **Docker**-контейнерах.

# Стек технологий

*   **Python 3.12** — основной язык.
*   **Apache Airflow 2.10.4** — оркестрация и планировщик.
*   **Docker & Docker Compose** — контейнеризация и простота запуска.
*   **PostgreSQL 16** — метабаза для Airflow.
*   **SQLite** — компактное хранилище для результатов ETL.
*   **Git** — контроль версий.

##  Архитектура пайплайна

1.  **Extract (Извлечение):*** Запрос к публичному API (`exchangerate-api.com`) для получения актуального курса USD/RUB.
2.  **Transform (Трансформация):** Извлечение значения курса и форматирование временной метки.
3.  **Load (Загрузка):** Сохранение подготовленной пары (`timestamp`, `rate`) в таблицу `usd_rates` базы данных SQLite.
